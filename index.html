Mettre sur la Garmin

Chaque séance peut être téléchargée en fichier d'entraînement .fit : enchaînement des étapes, durées et bips. La montre affiche le nom de l'exercice, pas l'animation.

Méthode USB (la plus fiable)

  1. Touche ⌚ .fit sur une séance : le fichier se télécharge.
  2. Branche la montre à un ordinateur avec son câble (sur Mac : appli gratuite OpenMTP).
  3. Copie le fichier dans le dossier GARMIN / NewFiles.
  4. Débranche : la montre l'importe. Tu le trouves dans Entraînements (menu de l'activité Cardio, Musculation, Yoga… ou Course).

Depuis la tablette Android

Avec un câble USB-C (ou un adaptateur OTG) : la montre apparaît dans « Fichiers », copie le .fit dans GARMIN / NewFiles. Ça ne marche pas avec tous les modèles.

Si la montre refuse un fichier, note son modèle et le message affiché : on corrigera le format.
FC en direct

La montre envoie la fréquence cardiaque en Bluetooth, la tablette l'affiche pendant la séance. Ta montre continue d'enregistrer l'activité normalement.

1. Sur la montre

  1. Fenix 6 : depuis le widget fréquence cardiaque, maintiens MENU › Options FC › Diffuser pendant l'activité, puis démarre une activité (Cardio, Musculation…). Ou, sans activité : Options FC › Diffuser la FC.
  2. Epix Pro : démarre l'activité, puis dans ses réglages : Diffuser la FC. Ou, sans activité : menu des commandes (maintiens LIGHT) › icône Diffusion FC.
  3. Forerunner : selon le modèle, réglages de l'activité › Diffuser la FC, ou widget FC › Options › Diffuser pendant l'activité.

2. Sur la tablette

  1. Bluetooth activé. Ouvre la page dans Chrome, depuis son adresse GitHub (https) : un fichier ouvert directement ne peut pas utiliser le Bluetooth.
  2. Touche ❤ Connecter à côté du prénom, choisis la montre dans la liste (« Fenix 6 », « Epix Pro »…), puis Associer.
  3. Si la liste est vide : autorise Chrome à accéder aux « Appareils à proximité » et à la position (Réglages Android › Applis › Chrome › Autorisations).
Deux montres peuvent être connectées en même temps : une par participant. Les zones sont calculées depuis la FC au seuil de chaque profil.
Sur iPad, Safari ne sait pas faire : il faut l'appli gratuite Bluefy. La diffusion use plus vite la batterie de la montre.
